# Карта «лучшее из BingX-скиллов» → инструменты нашего шлюза

Принцип: переносим ИДЕИ и покрываем их своими агентными инструментами
(чистый Python, без тяжёлых зависимостей), а не копируем код. Агент вызывает
инструмент сам — в этом превосходство над скиллами, которые требуют
LLM-оркестрации поверх.

| BingX-скилл | Что взяли (идея) | Наш инструмент | Чем лучше |
|---|---|---|---|
| bingx-sentiment-dashboard (funding heatmap, OI anomalies) | карта фандинга по всем рынкам | `funding_heatmap` | 296 рынков dYdX одним вызовом; годовая нормализация; ready-to-alert формат; считает агент, а не человек с дашбордом |
| bingx-technical-analysis (78 индикаторов, pandas-ta) | базовый TA-снимок | `market_ta` | ноль зависимостей (RSI/EMA/ATR/BB в 60 строках); вызывается агентом в цикле; остальное агент выводит сам — он и есть «78 индикаторов» |
| bingx-dynamic-sl-tp (ATR-стопы, breakeven, trailing) | ATR-план риска | `suggest_stops` | SL/TP/breakeven/trailing + RR одной функцией; агент управляет позицией сам, без ручной перестановки |
| bingx-trade-review (winrate, журнал) | обзор исполнения | `fills_review` | по любому адресу сети (у BingX — только свой аккаунт); maker/taker, объёмы, рынок-микс |
| bingx-trading-plan (6-мерный скор) | скелет решения агента | демо №3 | скор собирает сам агент из market_ta + funding_heatmap + suggest_stops — расширяемо без новой логики в коде |
| bingx-maker-entry (мультиуровневые лимитки) | план входа | `suggest_stops` + `candles` (v1); мультиуровневость — в майлстоуне | агенту достаточно уровней и цены; исполнение — торговый модуль |

Взятых идей достаточно для v1; остальное (copytrade, announcements, spot,
sub-accounts) — вне домена dYdX-шлюза, не переносим.

Честные ограничения, найденные при переносе:
- у индексера dYdX НЕТ per-fill PnL → винрейт из филлов невозможен; будет из
  кривой historical-pnl (майлстоун «PnL-движок»);
- ордербука в публичном индексере нет → мейкер-пегинг по recent_trades.
