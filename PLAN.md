# dYdX Agent Gateway — MCP-шлюз для ИИ-агентов (основной грантовый продукт)

Статус: 2026-08-23, решение пользователя. Прямое попадание в заявленный
приоритет dYdX EDP на 2026: «AI agents». Формула продукта: **любой ИИ-агент
подключается к dYdX одним MCP-сервером — данные, аналитика, торговля.**

## Почему это сильнее аналитики-дашборда

- Приоритет казны на 2026 заявлен словами «AI agents» — заявка с нашим
  продуктом цитирует их собственный roadmap.
- Умений требует ровно наших: мы сами — работающий дуэт «агент+человек»;
  весь этот сервер пишется агентом для агентов.
- Конкурентов нет: Copin/Hyperscreener-класс — аналитика Hyperliquid,
  «агентного шлюза» dYdX не существует ни у кого (проверено ресёрчем).
- Аналитика trader-PnL (старый план service-plan.md) становится МОДУЛЕМ,
  а не продуктом — и её слабый пользовательский спрос перестаёт быть риском.
- Размещение ключей у пользователя (self-host / его ключи) — нет
  регуляторной нагрузки на нас.

## Поверхность инструментов v1

Публичные (без ключей, индексер):
- `list_markets` — все перп-рынки: цена, OI, объём, фандинг
- `market_detail(ticker)` — рынок глубоко: оракул-цена, OI, следующий
  фандинг, сводка свечей
- `candles(ticker, resolution, limit)` — OHLCV + OI
- `recent_trades(ticker, limit)` — лента сделок рынка
- `trader_profile(address)` — снимок: equity, позиции + кривая PnL
  (historical-pnl), депозит-скорр. метрики v0
- `trader_positions(address)` — открытые позиции
- `height` — высота/время цепи (liveness-чек агентов)

Торговые (ключи ПОЛЬЗОВАТЕЛЯ, официальный v4-client-py, условный импорт):
- `place_order(ticker, side, type, size, price?, clientId?)`
- `cancel_order(id)` / `cancel_all(ticker?)`
- `my_orders` / `my_positions` / `my_fills(limit)`

Транспорт: stdio (Claude Desktop, локальные агенты) сейчас; streamable HTTP
(hosted) — после гранта. Ответы: JSON + человекочитаемая сводка.

## MVP-объём и план

- Ядро (2 недели): сервер + публичные инструменты + README с конфигом для
  Claude Desktop/Codex + 3 демо-сценария («агент мониторит фандинг и
  сообщает», «профиль трейдера перед копированием», «агент торгует по
  правилу с моего разрешения»).
- Неделя 3: торговые инструменты поверх официального клиента, приватный
  smoke-тест на testnet dYdX.
- Публикация: репо open-source + видео-демо + X-тред + пост на
  dydx.forum → заявка EDP (~$18–24k, 2 мес, майлстоуны: инструменты →
  hosted HTTP → аналитический модуль trader-PnL → библиотека примеров).

## Дифференциация в заявке (таблица)

| Кто | Что | Чем не мы |
|---|---|---|
| Copin | аналитика копитрейда Hyperliquid | не dYdX, не агенты |
| Нативные rankings | лидерборд без API | не для агентов, без торговли |
| Telegram-бот (грантополучатель) | ручной трейдинг в TG | не ИИ-агент, не MCP |
| Numia | enterprise-дашборды | без API для агентов, без торговли |

## Риски и ответы

- «Агенты не торгуют сами» → MVP фокус на данные/аналитику + подтверждаемые
  действия с явным разрешением человека (human-in-the-loop по умолчанию).
- Безопасность ключей → self-host, ключи не покидают машину агента.
- Малый трафик dYdX → продаём казне рост API-активности: каждый подключённый
  агент = новые API-вызовы (60%+ активности уже API — растим то, что они
  измеряют).
